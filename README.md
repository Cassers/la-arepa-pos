# La Arepa · Proyecto de punto de venta

Propuesta para implementar una caja con Odoo Community 19 en un local de Bogotá. Incluye equipos, montaje, dos comandas impresas por pedido y avisos internos por Telegram.

- [Abrir cotización interactiva en GitHub Pages](https://cassers.github.io/la-arepa-pos/)
- [Leer el plan técnico y las pruebas de entrega](PLAN.md)

Marca o desmarca funciones en la cotización para recalcular los subtotales. Con el alcance inicial, la mano de obra suma **$3.200.000 COP** y queda en **$1.600.000 COP** con el descuento del 50 %. Los equipos con UPS suman **$1.690.140 COP**, para un total de **$3.290.140 COP**. Las referencias de hardware corresponden al 8 de noviembre de 2026.

La cotización está en `docs/` y usa HTML, CSS y JavaScript. GitHub Pages publica esa carpeta desde `main`. Para verla localmente, abre `docs/index.html` en el navegador.
