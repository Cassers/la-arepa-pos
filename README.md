# La Arepa · Proyecto de punto de venta

Propuesta para implementar una caja con Odoo Community 19 en un local de Bogotá. Incluye equipos, montaje, dos comandas impresas por pedido y avisos internos por Telegram.

- [Abrir cotización interactiva en GitHub Pages](https://cassers.github.io/la-arepa-pos/)
- [Leer el plan técnico y las pruebas de entrega](PLAN.md)

Marca o desmarca funciones en la cotización para recalcular los subtotales. Con el alcance inicial, la mano de obra suma **$3.200.000 COP** y queda en **$1.600.000 COP** con el descuento del 50 %. Con el Dell Latitude 5420 usado, la guaya Wedge y la UPS, los equipos suman **$1.756.040 COP**, para un total de **$3.356.040 COP**. La batería nueva de 63 Wh es opcional y suma **$289.000 COP** al elegirla. Con el HP 14-dq3502la nuevo y la UPS, el total es **$3.481.140 COP**. Las referencias de hardware corresponden al 8 y 9 de noviembre de 2026.

La cotización está en `docs/` y usa HTML, CSS y JavaScript. GitHub Pages publica esa carpeta desde `main`. Para verla localmente, abre `docs/index.html` en el navegador.
